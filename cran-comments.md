## R CMD check results

Status: no ERRORs. The remaining WARNINGs/NOTEs are all inherent to the
'instantiate' Stan-packaging pattern or local tooling:

- WARNING (CRAN incoming feasibility): "Strong dependencies not in
  mainstream repositories: cmdstanr". cmdstanr is not on CRAN by design;
  it is declared via `Additional_repositories:
  https://stan-dev.r-universe.dev/`, following the packaging pattern
  recommended by the 'instantiate' package (itself on CRAN). The check
  itself reports "Availability using Additional_repositories
  specification: cmdstanr yes".
- WARNING (compilation flags): `-Wno-*` flags originate from the
  Makevars scaffolding generated by `instantiate::stan_package_configure()`
  and from CmdStan's own build system, not from hand-written flags.
- NOTE (HTML validation skipped): local HTML Tidy too old; environment
  issue only. Likewise the local "checkbashisms script not found" WARNING
  and "unable to verify current time" NOTE.
- The `URL`/`BugReports` links (github.com/paleopresto/BayGMST_R)
  currently 404 for unauthenticated requests because the repository is
  private. **Make the repository public before submitting**, or the URL
  check will fail on CRAN's side too.

All examples, tests, and vignette chunks that sample a Stan model are
guarded with `instantiate::stan_cmdstan_exists()` and/or `\donttest{}`,
so the package checks cleanly on machines without CmdStan.
